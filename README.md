# design-editor-skill

Agent skill for designing with [Design Editor](https://github.com/kemalcalak/design-editor): the `de` CLI, the batch design DSL, the MCP tools, the PenNode schema and UI design guidance.

## Install

With the editor's CLI installed:

```bash
de install            # detected agents
de install --target claude
```

Or add it to Claude Code manually as a plugin marketplace pointing at `kemalcalak/design-editor-skill`.

The skill itself is `skills/design-editor/SKILL.md`.
